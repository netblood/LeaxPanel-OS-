# LeaxPanel(os) - نظام تشغيل سحابي كامل

LeaxPanel(os) هو نظام تشغيل سحابي كامل مبني باستخدام JavaScript خالص (Node.js 22+, Express, PostgreSQL, Redis, EJS, HTMX, Socket.IO). بدون خطوة بناء، بدون TypeScript، بدون أطر عمل أمامية.

## المميزات

- **المصادقة المؤسسية**: RBAC/PBAC، مصادقة ثنائية (2FA/TOTP)، جلسات، JWT
- **منصة الذكاء الاصطناعي**: وكلاء الذكاء الاصطناعي، استضافة النماذج، سوق التطبيقات
- **استضافة المواقع والبوتات**: بوتات ديسكورد، تيليجرام، واتساب؛ نشر المواقع
- **مراكز الاتصال**: مراسلة متعددة القنوات
- **تكامل N8N**: أتمتة سير العمل
- **مركز قواعد البيانات**: مثيلات قواعد بيانات مدارة
- **مركز البريد الإلكتروني**: حسابات SMTP وحملات بريد إلكتروني
- **مركز النطاقات**: إدارة النطاقات مع تكامل Cloudflare
- **مركز التخزين**: دلاء تخزين وأشياء كائنات
- **تكامل Cloudflare**: DNS، مناطق، CDN
- **استضافة الذكاء الاصطناعي**: نماذج ذكاء اصطناعي مستضافة ذاتياً
- **السوق**: تطبيقات، قوالب، إضافات
- **المراقبة**: مقاييس النظام في الوقت الفعلي
- **الشفاء التلقائي**: استعادة الخدمة تلقائياً
- **النسخ الاحتياطية**: نسخ احتياطية مجدولة وعند الطلب
- **الأمان**: سجلات تدقيق، أحداث أمنية، تحديد المعدل
- **مدير الملفات**: إدارة ملفات على الويب
- **العلامة البيضاء**: علامات تجارية ونطاقات مخصصة
- **التعدد المستأجر**: بيئات عملاء معزولة
- **الفوترة**: تكامل Stripe و PayPal
- **مركز الطلبات**: نظام تذاكر الدعم

## البدء السريع

### Windows

1. انقر نقراً مزدوجاً على `install.bat` لتثبيت التبعيات
2. انقر نقراً مزدوجاً على `run.bat` لبدء الخادم
3. افتح http://localhost:3000 في متصفحك

### Linux / macOS

```bash
chmod +x install.sh run.sh
./install.sh   # تثبيت التبعيات
./run.sh       # بدء الخادم
```

ثم افتح http://localhost:3000 في متصفحك.

### التثبيت السريع من GitHub

قم بتنزيل وتشغيل المثبت مباشرة من GitHub في أمر واحد:

**Windows (PowerShell، شغّل ك مسؤول):**
```powershell

```

**Linux / macOS:**

ثم ابدأ الخادم وافتح http://localhost:3000 في متصفحك:

**Windows:**
```powershell

node server.js
```

**Linux / macOS:**
```bash
chmod +x run.sh
./run.sh
# أو
node server.js
```

### كلمات المرور المُنشأة تلقائياً

جميع المثبتات (`install.ps1`، `install.sh`، `install.bat`) تنشئ كلمات مرور قوية عشوائية لكل خدمة وتكتبها في ملف `.env` تلقائياً:

- **قاعدة بيانات PostgreSQL** (`DB_PASSWORD`) — كلمة مرور عشوائية 16 حرفاً
- **Redis** (`REDIS_PASSWORD`) — كلمة مرور عشوائية 16 حرفاً
- **Minio** (`MINIO_PASSWORD`) — كلمة مرور عشوائية 16 حرفاً
- **سر الجلسة** (`SESSION_SECRET`) — سر عشوائي 32 حرفاً
- **سر JWT** (`JWT_SECRET`) — سر عشوائي 32 حرفاً
- **مفتاح التشفير** (`ENCRYPTION_KEY`) — مفتاح عشوائي 32 حرفاً

يقوم المثبت أيضاً بإنشاء ملف `docker-compose.override.yml` لربط كلمات المرور بـ Docker، وتشغيل PostgreSQL/Redis/Minio عبر Docker، وتشغيل الترحيلات والبذور، وطباعة جميع بيانات الاعتماد في النهاية. **احفظ بيانات الاعتماد المعروضة — لن تُعرض مرة أخرى.**

## التثبيت اليدوي

```bash
# تثبيت التبعيات
npm install

# نسخ إعدادات البيئة
cp .env.example .env
# عدل .env بإعداداتك

# بدء الخادم
node server.js
```

## إعداد قاعدة البيانات (الإنتاج)

يحتاج LeaxPanel(os) إلى PostgreSQL و Redis للوظائف الكاملة.

```bash
# باستخدام Docker Compose
docker-compose up -d

# تشغيل الترحيلات
npm run migrate

# تشغيل بيانات البذور
npm run seed
```

## متغيرات البيئة

متغيرات البيئة الرئيسية في `.env`:

| المتغير | الوصف | القيمة الافتراضية |
|----------|-------------|---------|
| `NODE_ENV` | وضع البيئة | `development` |
| `PORT` | منفذ الخادم | `3000` |
| `DB_HOST` | مضيف PostgreSQL | `localhost` |
| `DB_PORT` | منفذ PostgreSQL | `5432` |
| `DB_NAME` | اسم قاعدة البيانات | `leaxos` |
| `DB_USER` | مستخدم قاعدة البيانات | `leaxos` |
| `DB_PASSWORD` | كلمة مرور قاعدة البيانات | تُنشأ تلقائياً (المثبت) |
| `REDIS_URL` | عنوان اتصال Redis | `redis://localhost:6379` |
| `SESSION_SECRET` | سر توقيع الجلسة | تُنشأ تلقائياً (المثبت) |
| `JWT_SECRET` | سر توقيع JWT | تُنشأ تلقائياً (المثبت) |
| `ENCRYPTION_KEY` | مفتاح تشفير AES-256-GCM (32 حرفاً) | تُنشأ تلقائياً (المثبت) |

## استكشاف الأخطاء وإصلاحها

### الخادم لا يبدأ

1. تأكد من تثبيت Node.js 22+: `node --version`
2. تأكد من تثبيت التبعيات: `npm install`
3. تحقق من وجود ملف `.env` وتكوينه بشكل صحيح
4. تحقق من تشغيل PostgreSQL و Redis (للوظائف الكاملة)

### أخطاء اتصال قاعدة البيانات

1. تأكد من تشغيل PostgreSQL على المضيف والمنفذ المconfigured
2. تحقق من `DB_USER`، `DB_PASSWORD`، و `DB_NAME` في `.env`
3. تشغيل الترحيلات: `npm run migrate`
4. تشغيل البذور: `npm run seed`

### أخطاء اتصال Redis

1. تأكد من تشغيل Redis على المنفذ 6379
2. تحقق من `REDIS_URL` في `.env`
3. سيعمل الخادم في وضع متدهور بدون Redis (تستخدم الجلسات تخزين الذاكرة)
